# M1 Dashboard: redesign preview

A clickable prototype of the proposed M1 dashboard redesign.

**▶ Open it:** https://mediaonemultimedia.github.io/m1-redesign-preview/

- Use the **Standard / Premium / Bold** toggle in the top bar to compare the three directions. The moon icon switches light and dark.
- Press **⌘K** (Ctrl-K) for the command palette.

All client names, people and figures are fictional.
